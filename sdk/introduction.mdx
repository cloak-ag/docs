Cloak SDK exposes two interfaces, with UTXO as the primary integration path:

- **Note API** via `CloakSDK` (`deposit`, `withdraw`, `send`, `swap`)
- **UTXO API** via top-level functions (`transact`, `transfer`, `swapUtxo`, ...)

Most production integrations use the UTXO API (`/transact`, `/transact_swap`).

## Installation

<CodeGroup>
```bash web3.js (npm)
npm install @cloak.ag/sdk @solana/web3.js
```

```bash Solana Kit app (npm)
npm install @cloak.ag/sdk @solana/web3.js @solana/kit
```

```bash web3.js (yarn)
yarn add @cloak.ag/sdk @solana/web3.js
```

```bash Solana Kit app (yarn)
yarn add @cloak.ag/sdk @solana/web3.js @solana/kit
```

```bash web3.js (pnpm)
pnpm add @cloak.ag/sdk @solana/web3.js
```

```bash Solana Kit app (pnpm)
pnpm add @cloak.ag/sdk @solana/web3.js @solana/kit
```

```bash web3.js (bun)
bun add @cloak.ag/sdk @solana/web3.js
```

```bash Solana Kit app (bun)
bun add @cloak.ag/sdk @solana/web3.js @solana/kit
```
</CodeGroup>

Why both packages for Kit apps? Cloak's transaction APIs currently accept `@solana/web3.js` `Connection`/`PublicKey` types. You can still use Kit for RPC reads and signer architecture in your app, then pass a thin web3.js bridge to Cloak transaction calls.

See: [Solana Kit Integration](/sdk/kit-integration)

For swap flows, install SPL token utilities too:

```bash
npm install @solana/spl-token
```

## Minimal note-based example

<CodeGroup>
```typescript web3.js (direct)
import { CloakSDK } from "@cloak.ag/sdk";
import { Connection, Keypair, PublicKey } from "@solana/web3.js";

const connection = new Connection("https://api.mainnet-beta.solana.com", "confirmed");
const keypair = Keypair.fromSecretKey(/* Uint8Array secret key */);

const sdk = new CloakSDK({
  keypairBytes: keypair.secretKey,
  network: "mainnet",
  programId: new PublicKey("c1oak6tetxYnNfvXKFkpn1d98FxtK7B68vBQLYQpWKp"),
});

const deposit = await sdk.deposit(connection, 100_000_000);
const recipient = Keypair.generate().publicKey;

const sent = await sdk.send(connection, deposit.note, [
  { recipient, amount: 30_000_000 },
]);

console.log("Send tx:", sent.signature);
```

```typescript Solana Kit + web3.js bridge
import { createSolanaRpc, address } from "@solana/kit";
import { createUtxo, createZeroUtxo, generateUtxoKeypair, transact } from "@cloak.ag/sdk";
import { Connection, Keypair, PublicKey } from "@solana/web3.js";

const RPC_URL = "https://api.mainnet-beta.solana.com";
const RELAY_URL = "https://your-relay.example.com";

// Kit client for read paths.
const kitRpc = createSolanaRpc(RPC_URL);

// Cloak transaction calls currently use web3.js connection/signing types.
const connection = new Connection(RPC_URL, "confirmed");
const signer = Keypair.fromSecretKey(/* Uint8Array secret key */);
const programId = new PublicKey("c1oak6tetxYnNfvXKFkpn1d98FxtK7B68vBQLYQpWKp");

const { value: beforeLamports } = await kitRpc
  .getBalance(address(signer.publicKey.toBase58()))
  .send();

const owner = await generateUtxoKeypair();
const output = await createUtxo(20_000_000n, owner);

await transact(
  {
    inputUtxos: [await createZeroUtxo()],
    outputUtxos: [output],
    externalAmount: 20_000_000n,
    depositor: signer.publicKey,
  },
  {
    connection,
    programId,
    relayUrl: RELAY_URL,
    depositorKeypair: signer,
  }
);

console.log("Signer balance before:", beforeLamports.toString());
```

```typescript Wallet adapter
import { useMemo } from "react";
import { CloakSDK } from "@cloak.ag/sdk";
import { useWallet } from "@solana/wallet-adapter-react";
import { PublicKey, Connection, Keypair } from "@solana/web3.js";

export function useCloakNoteClient() {
  const { publicKey, signTransaction, sendTransaction } = useWallet();

  return useMemo(() => {
    if (!publicKey || !signTransaction || !sendTransaction) return null;

    return new CloakSDK({
      wallet: { publicKey, signTransaction, sendTransaction },
      network: "mainnet",
      programId: new PublicKey("c1oak6tetxYnNfvXKFkpn1d98FxtK7B68vBQLYQpWKp"),
    });
  }, [publicKey, signTransaction, sendTransaction]);
}

async function exampleFlow(sdk: CloakSDK, connection: Connection) {
  const deposit = await sdk.deposit(connection, 100_000_000);
  const recipient = Keypair.generate().publicKey;
  await sdk.send(connection, deposit.note, [{ recipient, amount: 30_000_000 }]);
}
```
</CodeGroup>

## Core protocol fees

Shared protocol constants:

- SOL withdrawal fee: `0.005 SOL + floor(gross * 0.3%)`
- SPL withdrawal fee: `ceil(0.005 SOL converted to token units) + floor(gross * 0.3%)`
- Minimum deposit: `10_000_000` lamports (0.01 SOL)

SDK exports user-facing helpers for both paths:

- SOL: `calculateSolFeeLamports`, `calculateSolNetAmountLamports`
- SPL: `calculateSplFeeTokenAmount`, `calculateSplNetAmountToken`, `calculateSplFixedFeeTokenAmount`
- Q64.64 quote helpers: `tokenPerSolBaseUnitsToQ64`, `q64ToTokenPerSolBaseUnits`
