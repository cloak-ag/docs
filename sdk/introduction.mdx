Current runtime defaults:

- SDK package in this repo: `@cloak.ag/sdk@0.1.0`
- Default program constant: `zh1eLd6rSphLejbFfJEneUwzHRfMKxgzrgkfwA6qRkW`
- Hosted circuit base: `https://cloak-circuits.s3.us-east-1.amazonaws.com/circuits/0.1.0`

## Install

<CodeGroup>
```bash @solana/web3.js
npm install @cloak.ag/sdk @solana/web3.js
```

```bash @solana/kit
npm install @cloak.ag/sdk @solana/web3.js @solana/kit
```
</CodeGroup>

Why both for Kit apps? The current transaction path in Cloak SDK consumes `@solana/web3.js` connection/signing types, while Kit can still be your primary RPC/signer architecture at app level.

## Minimal setup snippets

<CodeGroup>
```typescript web3.js app
import { CLOAK_PROGRAM_ID, setCircuitsPath } from "@cloak.ag/sdk";
import { Connection } from "@solana/web3.js";

const connection = new Connection(process.env.SOLANA_RPC_URL!, "confirmed");
setCircuitsPath("https://cloak-circuits.s3.us-east-1.amazonaws.com/circuits/0.1.0");

console.log("Program:", CLOAK_PROGRAM_ID.toBase58());
```

```typescript Solana Kit app
import { CLOAK_PROGRAM_ID } from "@cloak.ag/sdk";
import { createSolanaRpc } from "@solana/kit";
import { Connection } from "@solana/web3.js";

const rpcUrl = process.env.SOLANA_RPC_URL!;
const kitRpc = createSolanaRpc(rpcUrl);
const connectionBridge = new Connection(rpcUrl, "confirmed");

console.log("Program:", CLOAK_PROGRAM_ID.toBase58());
console.log("Kit + web3 bridge ready", !!kitRpc, !!connectionBridge);
```
</CodeGroup>
