This page is the first-run path: one script that shields 0.01 SOL, sends it privately, and
withdraws it to your wallet.

<Warning>
**Cloak runs on Solana mainnet only, and there is no test network.** Test with small
amounts: the smallest SOL deposit is 0.01 SOL (about 0.005 SOL of it comes back out as the withdraw
fee, see [Fees](#what-this-costs)). Use a wallet you can afford to experiment with.
</Warning>

<Note>
This is the server-side path: a keypair file signs everything, so nothing prompts. A browser wallet
signs through `signerFromWalletAdapter` and `signMessage` instead; read
[Request authentication](/sdk/request-authentication) before you port this to a frontend.
</Note>

## 1. Install

You need Node 22 or later and a mainnet RPC URL of your own (Cloak hosts no RPC).

```bash
npm install @cloak.dev/sdk@^0.2.11 @solana/kit
npm install --save-dev tsx typescript
```

## 2. Keys

Cloak derives every key from one 32-byte seed. The script generates it on the first run and stores
it in `cloak-seed.hex`; treat that file like a private key. **If you lose the seed you lose access
to your shielded notes**, which is why the script never uses a random throwaway key.

From the seed come two things you will see in the code:

- `ownerUtxoKeypair`: owns your notes and is required on every spend flow.
- `nk`: a view-only key. It can find and read your notes, never spend them, so it can be shared
  with an auditor.

## 3. The script

Save as `quickstart.ts`:

```ts
import { existsSync, readFileSync, writeFileSync } from "node:fs";
import {
  CLOAK_PRODUCTION_RELAY_URL,
  CLOAK_PROGRAM_ID,
  NATIVE_SOL_MINT,
  createCloakRpc,
  createRecoverableDepositUtxo,
  createZeroUtxo,
  deriveSpendKey,
  deriveUtxoKeypairFromSpendKey,
  fullWithdraw,
  generateMasterSeed,
  getNkFromUtxoPrivateKey,
  hexToBytes,
  serializeUtxo,
  signerFromSecretKey,
  transact,
  transfer,
} from "@cloak.dev/sdk";

const rpcUrl = process.env.SOLANA_RPC_URL;
const keypairPath = process.env.KEYPAIR_PATH;
if (!rpcUrl || !keypairPath) {
  throw new Error("Set SOLANA_RPC_URL and KEYPAIR_PATH.");
}

const connection = createCloakRpc(rpcUrl);
const signer = await signerFromSecretKey(
  Uint8Array.from(JSON.parse(readFileSync(keypairPath, "utf8")) as number[]),
);

// Persistent seed: generated once, then reused on every run.
const SEED_FILE = "./cloak-seed.hex";
if (!existsSync(SEED_FILE)) {
  writeFileSync(SEED_FILE, generateMasterSeed().seedHex, { mode: 0o600 });
}
const seed = hexToBytes(readFileSync(SEED_FILE, "utf8").trim());

const { sk_spend } = deriveSpendKey(seed);
const ownerUtxoKeypair = await deriveUtxoKeypairFromSpendKey(sk_spend);
const nk = getNkFromUtxoPrivateKey(ownerUtxoKeypair.privateKey); // view-only

// `relayUrl` has no default. This build accepts exactly one origin.
const options = {
  connection,
  programId: CLOAK_PROGRAM_ID,
  relayUrl: CLOAK_PRODUCTION_RELAY_URL,
  depositorKeypair: signer,
  walletPublicKey: signer.address,
  chainNoteViewingKeyNk: nk,
  ownerUtxoKeypair,
};

// 1) Deposit 0.01 SOL (the minimum).
const amount = 10_000_000n;
const { utxo, noteSalt } = await createRecoverableDepositUtxo({
  amount,
  viewingKeyNk: nk,
  ownerUtxoKeypair,
  mintAddress: NATIVE_SOL_MINT,
});
const deposited = await transact(
  {
    inputUtxos: [await createZeroUtxo(NATIVE_SOL_MINT)],
    outputUtxos: [utxo],
    externalAmount: amount,
    depositor: signer.address,
  },
  { ...options, chainNoteSalt: noteSalt },
);
console.log("deposited:", deposited.signature);

// 2) Private send. The recipient is a UTXO public key (a bigint). Here you send to
//    yourself so the script is self-contained; to pay someone else, pass the
//    `publicKey` of their UtxoKeypair.
const sent = await transfer(
  [deposited.outputUtxos[0]],
  ownerUtxoKeypair.publicKey,
  amount,
  { ...options, cachedMerkleTree: deposited.merkleTree },
);
console.log("sent privately:", sent.signature);

// Save the note before anything else can fail. The SDK stores nothing for you.
writeFileSync("./cloak-note.bin", serializeUtxo(sent.outputUtxos[0]));

// 3) Withdraw it all back to your wallet. The program takes its fee here.
const withdrawn = await fullWithdraw([sent.outputUtxos[0]], signer.address, {
  ...options,
  cachedMerkleTree: sent.merkleTree,
});
console.log("withdrawn:", withdrawn.signature);
```

## 4. Run it

```bash
export SOLANA_RPC_URL="https://<your-mainnet-rpc>"
export KEYPAIR_PATH="$HOME/.config/solana/id.json"   # absolute path to a Solana keypair file
npx tsx quickstart.ts
```

The wallet behind `KEYPAIR_PATH` needs a little over 0.01 SOL for the deposit plus network fees.
The first proof downloads the circuit bundle (cached afterwards), so expect the first run to be
slower.

## What this costs

Fees are charged by the on-chain program, only when value leaves the pool:

- Deposits and private sends carry no protocol fee (network fees only).
- Withdrawals pay `5_000_000` lamports plus 0.3% of the amount. Withdrawing 0.01 SOL returns about
  0.00497 SOL.

See [Fee model](/protocol/fee-model) for SPL pools and the full breakdown.
