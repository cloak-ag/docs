This quickstart runs the maintained send workflow script and validates your environment.

## 1) Install

<CodeGroup>
```bash web3.js app
npm install @cloak.ag/sdk @solana/web3.js
```

```bash Solana Kit app
npm install @cloak.ag/sdk @solana/web3.js @solana/kit
```
</CodeGroup>

## 2) Configure runtime

```bash
export SOLANA_RPC_URL="https://api.mainnet-beta.solana.com"
export CLOAK_RELAY_URL="https://your-mainnet-relay.example.com"
export CLOAK_PROGRAM_ID="zh1eLd6rSphLejbFfJEneUwzHRfMKxgzrgkfwA6qRkW"
```

## 3) Run private send example

From `sdk/` repo root:

```bash
yarn example:send
```

Script used: `sdk/examples/fast-send.ts`

Expected behavior:

- funds a temporary sender wallet
- creates a shielded deposit
- withdraws privately to recipient wallet
- prints funding/deposit/withdraw signatures

## 4) Run dry-run sanity checks (optional)

```bash
yarn test:examples
```

This validates example wiring without submitting live flows.
